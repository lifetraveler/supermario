# Resources

奔奔王国自动化识别资源。

## 目录

- city
- world
- battle
- hero
- alliance
- common

## 命名规范

推荐：

    scene_element_state.png

例如：

    city_world_button.png
    city_quest_button.png
    world_resource_wood.png
    world_monster.png
    battle_skill_button.png

不要使用：

    1.png
    test.png
    xxx.png

资源名称必须能够表达用途。
